## 工作原理

脚本通过远程加载两份核心数据文件实现功能增强：

### 1. 选修课分类数据（`xxk.json`）

当前为 **2026 版**（2026-09-08 采集）。首行为表头说明信息（`course_code` 为“课程号”），不会与真实课程号冲突，其后为课程记录：

> 💡 **多版本自动适配**：脚本会读取学号（如 `922110800724`，其中第 2-3 位 `22` 表示 2022 级）
> 推断入学年份，自动加载对应培养方案版本的分类数据；也可在成绩页学分统计窗口底部手动切换。
> 详见[多版本数据文件说明](./README.getXXK.md#多版本数据文件说明与适用场景)。

```json
[
  {
    "course_code": "00000011",
    "course_name": "坦克学",
    "category": "自然科技类"
  }
]
```

---

### 2. 教学大纲链接数据（`kcdg.json`）

```json
[
  {
    "id": "572BF3AE025044A7BDD7AF953460102C",
    "course_code": "161803E1"
  }
]
```

---

### 3.更新数据文件

当前内置数据版本：

| 数据文件 | 内容 | 版本 | 采集时间 |
|--------|------|------|---------|
| `xxk.json` | 选修课分类 | 2026 版 | 2026-09-08 |
| `kcdg.json` | 教学大纲映射 | 2022 版 | 2026-01-12 |

如果你认为已有的 `kcdg.json`版本已过时（例如您在 2027 年使用这个脚本），请参考
[课程大纲采集流程（README.getKCDG.md）](./README.getKCDG.md)
重新采集课程大纲。

如果你认为已有的 `xxk.json`版本已过时（例如您在 2030 年使用这个脚本），请参考
[选修课采集流程（README.getXXK.md）](./README.getXXK.md)
重新采集选修课分类数据。

> 选修课分类 2026 版的完整变更（新增 / 移除 / 类别调整）见
> [2026 版更新记录](./README.getXXK.md#数据版本与更新记录)
