## 选修课分类数据更新指南

一般而言，每四年南京理工大学会更新一次教学大纲，对应也会产生一批新的选修课列表。

- 2018 版课程分类：[查看链接](https://jwc.njust.edu.cn/77/2c/c1189a227116/page.htm)
- 2022 版课程分类：[查看链接](https://jwc.njust.edu.cn/b1/7f/c1189a307583/page.htm)
- **2026 版课程分类（当前内置）**：[查看链接](https://jwc.njust.edu.cn/95/50/c1189a365904/page.htm)

> 📌 每一版的**分类口径都不一样**，而不同年级的同学按各自入学时的方案执行。
> 因此本项目同时维护三版数据文件，详见[多版本数据文件说明与适用场景](#多版本数据文件说明与适用场景)。

我们可以看到，这些页面展示的是标准的表格，如下图所示：

![选修课分类页面](https://enhance.njust.wiki/docs/static/xxk_catag.png)

### 复制课程数据

从页面左上角选中整个表格区域，向下拖动并复制：

![复制表格数据](https://enhance.njust.wiki/docs/static/xxk_copy.png)

粘贴后得到类似如下的纯文本内容：

```
课程号

课程名

分类

00000011

坦克学

自然科技类

...
```

### 使用课程数据解析器

将上述完整内容（无需手动处理空行）粘贴至 [课程数据解析器](https://enhance.njust.wiki/tools/xxk.html)。

点击“解析为 JSON”，确认输出无误后点击“下载 JSON”：

![生成 JSON 数据](https://enhance.njust.wiki/docs/static/xxk_gen_json.png)

> 💡 若复制时包含了表格表头（课程号 / 课程名 / 分类），导出的 JSON 首条即为表头说明行。它的课程号是“课程号”，不会与真实课程号冲突，可以保留。

### 数据文件说明

每份数据文件的**首行均为表头说明信息**（`course_code` 为“课程号”），其后才是真实课程记录：

```json
[
  { "course_code": "课程号", "course_name": "课程名", "category": "2026版分类" },
  { "course_code": "00000011", "course_name": "坦克学", "category": "自然科技类" }
]
```

表头行的课程号是“课程号”，不会与真实课程号冲突，脚本加载后可安全忽略。

> 💡 仓库 `data/` 目录下除 `xxk.json` 外，还有 `xxk_2018.json` / `xxk_2022.json` / `xxk_2026.json`，
> 分别对应不同培养方案的分类口径，详见[多版本数据文件说明与适用场景](#多版本数据文件说明与适用场景)。

### 更新数据文件

如果你发现已有的 `xxk.json` 版本已过时，可以按照上述方法重新生成，并进行如下操作：

- 上传至服务器


然后将用户脚本中的分类数据地址替换为新的链接，例如：

```js
const CATEGORY_URL = 'https://fastly.jsdelivr.net/gh/NJUST-OpenLib/NJUST-JWC-Enhance@latest/data/xxk.json';
```
- 或提交 Pull Request 更新本项目的 `data/xxk.json`

## 多版本数据文件说明与适用场景

教务处每四年更新一次培养方案，**分类口径**（这门课算哪一类学分）也随之改变，
而不同年级的同学要按**各自入学当年的口径**统计选修课类别学分。
为此 `data/` 目录同时维护多份数据：

| 文件 | 课程清单 | 分类口径 | 适用人群 |
|---|---|---|---|
| `xxk.json`（脚本默认） | 2026 版最新课表，742 门 | 2026 版 | 2026 级起、执行新版方案的同学 |
| `xxk_2026.json` | 同上 | 2026 版 | 与 `xxk.json` 内容一致，供显式指定版本使用 |
| **`xxk_2022.json`** | **2026 版最新课表，742 门** | **2022 版** | **执行 2022 版方案的同学（老生学分统计）** |
| `xxk_2018.json` | 2018 版课表，1066 门 | 2018 版 | 仍执行 2018 版方案的年级 |

### 为什么 `xxk_2022.json` 用的是最新课表？

**课程清单**（现在能选哪些课）和**分类口径**（这门课算哪类学分）是两件事。

老同学同样会选修 2026 版新开的通识课（如 `00000581` 起的量子计算、AI、储能系列），
但仍需按入学当年的口径判断它们归属哪一类。因此 `xxk_2022.json` 采用
**「最新课程清单 + 2022 版分类口径」**的组合：

- 课程清单：与 2026 版完全一致，含 2026 新增的 47 门课程，TS 系列为 8 位课号（`TS000001`~`TS000005`）
- 分类口径：沿用 2022 版规则

> ⚠️ 它不是 2022 年当时的历史归档。若需要 2022 版原始课表（704 门，含 7 位课号 `TS00001`~`TS00005`、
> 以及已停开的 `00000442` / `00000443` / `00000452` / `00000453`），
> 请从本仓库提交历史中获取（`d959d44` 版本的 `data/xxk.json`）。

### 2022 口径 vs 2026 口径：只有 7 门课归属不同

两版课号集合完全相同（均为 742 门），差别仅在于以下 7 门课的类别归属：

| 课号 | 课程名 | `xxk_2022.json`（2022 口径） | `xxk_2026.json`（2026 口径） |
|---|---|---|---|
| 00000221 | 音乐乐理与音乐声学 | 自然科技类 | 艺术审美类 |
| 00000306 | 材料微观之美 | 自然科技类 | 艺术审美类 |
| 00000364 | 漫画艺术赏析与创作 | 人文素养类 | 艺术审美类 |
| 00000369 | 生活中的材料之美 | 自然科技类 | 艺术审美类 |
| 00000424 | 美学与人生 | 人文素养类 | 艺术审美类 |
| 00000529 | 陶艺制作及釉下彩烧成实践 | 自然科技类 | 艺术审美类 |
| HX000014 | 艺术概论 | 人文素养类 | 艺术审美类 |

其余 735 门课程两版归类一致。

若你执行的是 2022 版方案，却使用了 2026 版数据，上述 7 门课的学分会被记到「艺术审美类」名下，
导致各类别已修学分与实际要求不符 —— 这正是需要切换数据源的原因。

> 补充：`00W00201` 大学美育（同济大学版）在 2022 版原始数据中标注为“经济社会类（四史）”，
> 但 `xxk_2022.json` 采用了修正后的“艺术审美类”（与 2026 版一致），因为该课归属艺术类更符合课程性质。

### 脚本如何决定使用哪一版

脚本（v2.0.1.4 起）会**自动读取学号判断所属培养方案**，无需手动配置。

学号规则（以 `922110800724` 为例）：

| 片段 | 含义 |
|---|---|
| `9` | 本科生 |
| `22` | 入学年份后两位（即 2022 级） |
| `108` | 学院编码（自动化学院） |
| `00724` | 院内流水号 |

脚本从主框架页顶部的登录信息节点（`[id$="divLoginName"]`，形如「张三(922110800724)」）读取学号，
取**第 2-3 位**推算入学年份，再按下表匹配数据文件：

| 入学年份 | 使用的数据文件 | 说明 |
|---|---|---|
| 2026 级起 | `xxk.json`（2026 版） | 默认口径，未识别到学号时也走这一版 |
| 2022 级 ~ 2025 级 | `xxk_2022.json` | 最新课表 + 2022 版分类口径 |
| 2018 级 ~ 2021 级 | `xxk_2018.json` | 2018 版分类体系（类别名称不同） |

学号识别结果会缓存在浏览器本地，因此在成绩页等 iframe 子页面中同样生效。

### 手动指定版本（覆盖自动识别）

成绩页的「学分统计」悬浮窗底部有一行分类口径信息，右侧提供下拉框：

```text
📦 分类口径：2022 版（学号自动识别 · 2022 级）              [按学号自动 ▾]
```

可强制切换为 2018 / 2022 / 2026 任一版本，选择后会自动清空缓存并重新加载数据。

> ⚠️ `xxk_2018.json` 只包含 2018 版课表（1066 门），**2026 版新增的选修课在其中查不到类别**，不会显示标签。
> 若你需要「最新课表 + 2018 版分类口径」的组合，可参照 `xxk_2022.json` 的生成方式制作一份。

> 📝 `xxk_2018.json` 采用 2018 版五类体系（自然与科技类 / 人文与艺术类 / 经济与社会类 / 创新与创业类 / 经济与社会类（四史）），
> 类别名称与 2022、2026 版完全不同，仅适用于执行该版方案的年级。

### 开发者：直接写死数据源

若不使用自动识别逻辑，也可以把分类数据源写死为指定版本（注意脚本更新后会被覆盖）：

```js
const CATEGORY_URLS = [
    'https://enhance.njust.store/data/xxk_2022.json',
    'https://enhance.njust.wiki/data/xxk_2022.json',                                                               // 官方主节点
    'https://fastly.jsdelivr.net/gh/NJUST-OpenLib/NJUST-JWC-Enhance@latest/data/xxk_2022.json',                    // jsDelivr 全球加速
    'https://testingcf.jsdelivr.net/gh/NJUST-OpenLib/NJUST-JWC-Enhance@latest/data/xxk_2022.json',                 // jsDelivr Cloudflare
    'https://raw.githubusercontent.com/NJUST-OpenLib/NJUST-JWC-Enhance/refs/heads/main/data/xxk_2022.json'          // GitHub 原始文件（备用）
];
```
